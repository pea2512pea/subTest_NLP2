# SME Tax & Business RAG Assistant

แชตบอตภาษาไทยสำหรับค้นคำตอบเบื้องต้นเรื่องภาษีและการจดทะเบียนธุรกิจ SME โดยใช้เอกสารใน `data/` ร่วมกับ Google Gemini, FAISS และ Streamlit

ใน `data/` มีเอกสารภาษาไทย 10 ไฟล์ รวมมากกว่า 20,000 ตัวอักษร และ `test_questions.csv` มีคำถามทดสอบ 10 ข้อ โดย 2 ข้อกำหนดให้เอกสารไม่มีคำตอบ

## เริ่มใช้งานบน Windows PowerShell

เปิด PowerShell ที่โฟลเดอร์โปรเจกต์ แล้วรัน:

```powershell
.\.venv\Scripts\Activate.ps1
```

ถ้ายังไม่มี virtual environment ให้สร้างก่อน:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
```

เมื่อต้องการติดตั้งหรืออัปเดตไลบรารี ให้รัน:

```powershell
python -m pip install -r requirements.txt
```

ตั้งค่า Google AI Studio API key เฉพาะบนเครื่องนี้ใน `.streamlit/secrets.toml`:

```toml
GOOGLE_API_KEY = "ใส่คีย์ส่วนตัวของคุณที่นี่"
```

หรือกำหนด environment variable `GOOGLE_API_KEY` ใน terminal ที่ใช้รันแอป จากนั้นเริ่มแอปด้วย:

```powershell
streamlit run app.py
```

เมื่อใช้งานเสร็จ ออกจาก virtual environment ด้วย `deactivate`

## Deploy บน Streamlit Community Cloud (ทำเมื่อพร้อม)

1. Push ซอร์สโค้ดและ `data/` ไปยัง GitHub repository โดยไม่เพิ่ม `.streamlit/secrets.toml`, `.venv/` หรือไฟล์ที่มี API key ตรวจ `git status` และรายการไฟล์ที่จะ commit ก่อน push ทุกครั้ง
2. ที่ Streamlit Community Cloud เลือก **New app** แล้วเลือก repository, branch และ `app.py`
3. ในหน้า App settings / Secrets เพิ่ม `GOOGLE_API_KEY = "คีย์ส่วนตัว"` ผ่านช่อง Secrets ของ Streamlit เท่านั้น ห้ามใส่คีย์ใน repository หรือ notebook
4. Deploy แล้วตรวจ Logs และเปิดแอปจากหน้าต่างส่วนตัวหรืออุปกรณ์อื่นเพื่อยืนยันการเข้าถึง

โมเดล embeddings จะถูกดาวน์โหลดและสร้าง FAISS index ในครั้งแรกที่แอปเริ่มทำงาน จึงอาจใช้เวลาสักครู่และต้องคำนึงถึงหน่วยความจำของบริการโฮสต์

## ความปลอดภัยของคีย์

ห้ามใส่ API key จริงในไฟล์ที่ commit หรือ push ไป GitHub ไฟล์ `.streamlit/secrets.toml`, `.env` และ `.env.*` ถูกระบุไว้ใน `.gitignore` แต่ควรตรวจสอบ `git status` และ diff ทุกครั้งก่อน commit หากเคย push คีย์จริงขึ้น GitHub ให้เพิกถอนคีย์นั้นและสร้างคีย์ใหม่

## Domain และแหล่งที่มาของเอกสาร

หัวข้อของระบบคือผู้ช่วยผู้ประกอบการ SME มือใหม่ ครอบคลุมรูปแบบกิจการ การจัดตั้งบริษัท ภาษีเงินได้นิติบุคคล VAT ภาษีหัก ณ ที่จ่าย ประกันสังคม เครื่องหมายการค้า e-Tax Invoice การจดทะเบียนพาณิชย์ออนไลน์ และพื้นฐานบัญชี

ไฟล์ใน `data/` เป็นบทสรุปภาษาไทยที่จัดทำขึ้นเพื่อโครงการนี้โดยใช้ AI ช่วยร่างและเรียบเรียงตามหัวข้อที่กำหนด ไม่ใช่สำเนาตัวบทกฎหมายหรือการเชื่อมข้อมูลสดจากเว็บไซต์ราชการ จึงใช้ทดสอบการค้นคืนเอกสารเท่านั้น ไม่ควรใช้เป็นคำปรึกษาหรืออ้างว่าเป็นข้อมูลทางการ ก่อนนำข้อมูลไปใช้จริง ให้ตรวจสอบฉบับล่าสุดจากหน่วยงานที่เกี่ยวข้อง เช่น:

- กรมสรรพากร: https://www.rd.go.th/
- กรมพัฒนาธุรกิจการค้า: https://www.dbd.go.th/
- สำนักงานประกันสังคม: https://www.sso.go.th/
- กรมทรัพย์สินทางปัญญา: https://www.ipthailand.go.th/

## ตัวอย่าง Prompt ที่ใช้เป็นแนวทางพัฒนา

> สร้าง Streamlit chatbot ภาษาไทยสำหรับตอบคำถามภาษีและการจดทะเบียนธุรกิจ SME โดยใช้ RAG: โหลดไฟล์ `.txt` ใน `data/`, ทำความสะอาดและแบ่งข้อความเป็น chunks, สร้าง embeddings ด้วย multilingual Sentence Transformers, ค้นคืนด้วย FAISS และส่ง context ที่ค้นได้ให้ Google Gemini ผ่าน LangChain เท่านั้น กำชับโมเดลไม่ใช้ความรู้ภายนอก ระบุชื่อไฟล์อ้างอิง และตอบ `ไม่พบข้อมูลในเอกสารอ้างอิง` เมื่อ context ไม่พอ เก็บ API key ใน Streamlit secrets ซึ่งต้องไม่ commit ขึ้น GitHub

## ข้อจำกัดของข้อมูลและการทดสอบ

Prompt กำชับให้ตอบจาก context เท่านั้น และคืนข้อความ `ไม่พบข้อมูลในเอกสารอ้างอิง` เมื่อข้อมูลไม่เพียงพอ หน้าแชตแสดงชื่อไฟล์ที่ถูกค้นคืนและส่งเข้า context อย่างไรก็ตาม การปฏิเสธคำถามยังขึ้นกับการประเมินของ LLM จึงควรทดสอบทั้งคำถามที่มีและไม่มีคำตอบในเอกสารด้วย [test_questions.csv](./test_questions.csv) ก่อนใช้งานจริง เอกสารนี้ไม่ใช่คำปรึกษาทางกฎหมายหรือภาษี

ในหน้าแอปมีส่วน **ทดสอบคำถามจาก test_questions.csv** ให้เลือกข้อและกด **รันทดสอบ** ระบบจะส่ง prompt เข้า RAG chain เดียวกับหน้าแชต แล้วตรวจแบบง่ายตามคอลัมน์ `has_answer_in_docs`: `true` ผ่านเมื่อบอตให้คำตอบ ส่วน `false` ผ่านเมื่อบอตตอบ `ไม่พบข้อมูลในเอกสารอ้างอิง` การทดสอบนี้เช็กเพียงการตอบหรือปฏิเสธ ไม่ได้ตรวจความถูกต้องเชิงความหมายกับ `expected_answer`
